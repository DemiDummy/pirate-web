# Pirate Web

Sail a pirate sloop out of a bare home island, fight turn-based ship battles, take islands and grow your port.
**Play it at https://demidummy.github.io/pirate-web/**

Keyboard and mouse: click the sea to sail (or W A S D), click an island to gather, Shift or Space for all hands,
Tab for the chart, Esc for the menu and How to play.

This repo only holds the built game. It's published from a private source repo by `tools/release-pages.sh`.
